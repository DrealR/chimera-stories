# CHIMERA Story Engine

## Purpose

Story Mode is a structured counterfactual simulation for discovering dramatic possibilities inside declared bodies, constraints, memories, and asymmetries.

It can reveal:

- unexpected alliances;
- contradictions in world rules;
- character pressure points;
- missing material costs;
- paths no single author predicted;
- framework mechanisms that become dead ends when embodied;
- stronger interpretations of the same prime event.

It does not prove how real people or societies will behave.

## World-state declaration

Every run begins with:

```yaml
bodies: []
membranes: []
primes: []
resources: []
rhythms: []
mirror_systems: []
hidden_conditions: []
friction: []
open_possibilities: []
time_and_place: ""
scene_stop_condition: ""
```

### Bodies

Who exists and which shared bodies currently organize them?

### Membranes

What can each body perceive, access, retain, change, or refuse?

### Primes

Which events and constraints are fixed for this run?

### Resources

What material, information, authority, time, attention, and trust can move?

### Rhythms

Which cycles currently organize life and decision?

### Mirror systems

Which dashboards, myths, maps, memories, metrics, models, and stories shape each body's interpretation?

### Hidden conditions

What exists in world state but remains unavailable to selected characters?

### Friction

What prevents immediate resolution?

### Open possibilities

Which branches remain legally reachable before the scene begins?

## Simulation loop

```text
scene state
-> local perception
-> local weighting
-> character choice
-> action
-> consequence settlement
-> updated world state
-> other bodies receive partial returns
-> repeat or stop
```

The narrator maintains world continuity and consequence. Character operators choose action only from information and capacities available to that character.

## Output record

Every run should preserve:

- initial state identifier;
- participant and model provenance;
- private knowledge assignments;
- sequence of actions;
- world-state changes;
- rule contradictions discovered;
- unresolved causal questions;
- candidate lines, images, or events;
- human evaluation;
- canon state.

## Research posture

The engine asks:

> Given these bodies, values, constraints, memories, and asymmetries, what stories become reachable?

It does not ask:

> What would humanity definitely do?

The output is exploratory evidence about the designed world and the assumptions supplied to the run.
