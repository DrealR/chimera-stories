# Scoreboard and Map

The scoreboard compresses selected history. The map compresses selected relation.

Both are useful. Neither contains the game.

```text
living body
-> selected representation
-> operator weighting
-> changed movement
-> updated representation
```

The symbol recurs through:

- game interfaces;
- citizen rankings;
- model predictions;
- public reputation;
- ecological dashboards;
- institutional archives;
- war-probability displays.

The governing question is:

> Is this mirror helping the body play, or has the body begun playing for the mirror?

Use limit: rejecting one metric does not justify intuition without correction. The story needs plural mirrors and embodied return.
