# Waters Above and Below

The waters carry one field approached through two limits:

```text
above  -> accumulated cosmic memory
below  -> generative physical possibility
between -> embodied naming, choice, and relation
```

Genesis supplies a mythic carrier for differentiation, membrane, and relation. It does not function as a literal map of astrophysics.

Water imagery may recur through:

- ocean;
- rain;
- blood;
- tears;
- atmosphere;
- clouds;
- cooling systems;
- waves and interference.

These rhymes should remain differentiated. “All is water” is not a world rule.
