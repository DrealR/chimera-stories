# CHIMERA: Between the Waters — Narrative Substrate

> **This story does not contain the answer. It creates a world where more of us can enter the question together.**

This directory treats *Between the Waters* as a distinct CHIMERA body:

```text
narrative substrate
+ shared-world seed
+ simulation environment
+ collaboration membrane
```

The complete cinematic overview remains in the [story bible](../story-bibles/chimera-between-the-waters.md). This project body separates the material required to develop, simulate, adapt, and share the world without turning one draft into permanent scripture.

## Use order

1. Read [Story Mandate](00-vision/story-mandate.md).
2. Separate [Prime and Composite Canon](01-primes/canon-layers.md).
3. Enter one world or character body.
4. Use the [Story Engine](06-simulation/story-engine.md) for exploratory scenes.
5. Keep generated material in Sandbox until it passes [Canon Selection](06-simulation/canon-selection.md).
6. Preserve contributor lineage through [Provenance and Credit](07-collaboration/provenance-and-credit.md).

## Governing distinction

```text
Prime canon
= the minimum events and relations that make this world this world

Composite canon
= one selected arrangement built from those primes

Sandbox
= explored possibility

Candidate
= possibility with dramatic or structural value

Canon
= intentionally selected story history
```

The prime should be strong enough to generate variation and light enough to avoid imprisoning it.
